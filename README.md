# Weather Analytics Dashboard

Interactive weather analytics dashboard built with Apache Superset and PostgreSQL.

## Project Overview

This project analyzes daily weather data for October 2026.

## Technologies

- Apache Superset 6.0.0
- PostgreSQL 16
- SQL
- Docker
- Excel / CSV

## Dashboard Features

- Average, minimum and maximum temperature
- Daily precipitation analysis
- Wind speed analysis
- Atmospheric pressure trends
- Interactive date filter
- Daily weather data table

## Data

Weather observations for October 2026.
